# Data Analytics Portfolio — Precisão Análises Estratégicas

## Sobre o projeto
Portfólio de análise de dados de Fábio Sichineli (Precisão Análises Estratégicas):
projetos, exercícios e estudos de caso, desenvolvido durante a formação em Data Analytics da Cisco.

- Branch principal: `main`
- Estado atual: estrutura de pastas criada (com arquivos `.gitkeep`), ainda sem conteúdo

## Estrutura
- `cisco-data-analytics/modulos/` — um módulo por pasta (01_introducao … 07_comunicacao_resultados)
- `cisco-data-analytics/projetos/`, `exercicios/`, `estudos_caso/`
- `business-intelligence/`, `datasets/`, `documentacao/`

## Convenções
- Nomes de pastas e arquivos em minúsculas, sem acento, com `_` no lugar de espaço
- Cada projeto deve ter um README explicando: pergunta de negócio, dados usados, método e conclusões
- Análises em Python (pandas, matplotlib/plotly) ou notebooks Jupyter
- Não versionar dados sensíveis ou pessoais; datasets grandes devem ser referenciados, não copiados
- Ao adicionar conteúdo numa pasta, remover o `.gitkeep` dela

## Preferências
- Responder e escrever sempre em português do Brasil
- O usuário não é programador: explicar as análises e mudanças em linguagem simples

**Objetivo:** Desenvolver e documentar casos de análise de dados aplicados ao contexto de prospecção de clientes e estratégia de negócio.

## Pergunta de Negócio Central

**Quais ações atraem clientes para minha empresa de análises?**

Este portfólio documenta o processo de investigação desta questão através de metodologias de análise de dados.
